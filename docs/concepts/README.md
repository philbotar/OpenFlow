# Concepts

A workflow describes the work; a run executes it. Each node has its own conversation, and its connections decide which results it receives.

- [How OpenFlow works](how-openflow-works.md): follow a request through agents, tools, handoffs, and human decisions.
- [Workflows and runs](workflows-and-runs.md): the graph, execution states, and provider profiles.

To try these ideas, [build a two-agent workflow](../guides/first-workflow.md). Implementation details are in [Architecture](../architecture/README.md).
